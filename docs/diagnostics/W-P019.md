# W-P019: Runtime hardware-loop bound

A hardware loop bound is not known at elaboration. It can run in simulation through a procedural process, but it has no fixed unrolled RTL form.

## Example

Compile this example with `sioxc --emit ir runtime_loop.siox`.

```siox
module runtime_loop;
entity Cell { count: integer in, data: integer out }
impl Cell {
    process {
        data = 0;
        for i in 0..count { data = i; }
    }
}
entity E { count: integer in, data: integer out }
impl E { let child: Cell = { .count = count, .data = data }; }
```

## How to fix

Use constants, generic parameters or static shape attributes for elaboration-time loops. Keep a runtime loop only when its simulation-only behavior is intended; this warning does not advertise synthesis support.
