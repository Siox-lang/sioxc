# E-P009: Invalid pattern

A match pattern is not valid for the scrutinee, or uses a spelling that is not a supported pattern. A bare enum variant name is not a binding or wildcard.

## Example

Compile this example with `sioxc --emit ir invalid_pattern.siox`.

```siox
module invalid_pattern;
enum State { Idle, Run }
entity E { source: integer in, data: integer out }
impl E {
    match source {
        Idle => { data = 1; }
        _ => { data = 0; }
    }
}
```

## How to fix

Use a qualified variant such as `State::Idle` when matching that enum. Use a numeric pattern for this integer scrutinee, or `_` when a wildcard is intended. Preserve the scrutinee's width for bit patterns.
