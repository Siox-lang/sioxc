# E-P030: Attribute bound more than once

One declaration received two bindings for the same attribute. Unlike drivers, attribute bindings do not override or resolve one another.

## Example

Compile this example with `sioxc --emit ir duplicate_attr.siox`.

```siox
module duplicate_attr;
attr flag: Bool for let = false;
entity E { data: integer out }
impl E {
    attr flag for value = true;
    attr flag for value = false;
    let value: integer = 1;
    data = value;
}
```

## How to fix

Keep a single binding for this object. If the value depends on parameters, compute that value in the one permitted binding.
