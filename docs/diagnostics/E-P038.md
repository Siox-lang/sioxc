# E-P038: Unsupported recursive call frame

This runtime recursion needs a frame/copy-back contract the compiler cannot provide, or recursively changes argument types without a finite expansion. It is not a blanket rejection of all testbench recursion.

## Example

Compile this example with `sioxc --test recursive_storage.siox`.

```siox
// test
module recursive_storage;
fn bump(n: integer) -> integer {
    if n <= 0 { return 0; }
    n = n - 1;
    return 1 + bump(n);
}
#[test] entity T {}
impl T {
    let counter: integer = 3;
    process { await 1ns; print!("{}", bump(counter)); }
}
```

## How to fix

For a written parameter passed a signal, copy into a process local, call with that local and explicitly write back if intended. Keep recursive argument types stable. Use a loop when the required recursive contract is unavailable.
