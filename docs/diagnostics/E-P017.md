# E-P017: Unsupported expression or storage form

The selected lowering cannot represent this operation with a valid layout or storage contract. The message identifies the unsupported form; it is not permission to emit a guessed value.

## Example

Compile this example with `sioxc --test runtime_slice.siox`.

```siox
// test
module runtime_slice;
use std::bits::unsigned;
#[test] entity T {}
impl T {
    let data: unsigned[8] = 0;
    let low: integer = 1;
    process {
        print!("{}", data[low..0]);
    }
}
```

## How to fix

For the runtime slice in this example, use constant bounds, or a shift and a constant-width resize. Other instances of this code have operation-specific help; preserve the required type and effects when rewriting.
