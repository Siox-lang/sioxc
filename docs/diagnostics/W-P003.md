# W-P003: Unused internal signal

A driven internal component signal has no observable reader in the lowered hardware. Root/test-harness storage is not treated as an ordinary unused component local.

## Example

Compile this example with `sioxc --emit ir unused_signal.siox`.

```siox
module unused_signal;
entity E { source: Bit in, data: Bit out }
impl E {
    let unused: Bit = '0';
    unused = source;
    data = source;
}
entity H { source: Bit in, data: Bit out }
impl H { let dut: E = { .source = source, .data = data }; }
```

## How to fix

Remove the signal and its dead drive, or connect it to the intended observable logic. Check for a misspelled consumer before deleting state.
