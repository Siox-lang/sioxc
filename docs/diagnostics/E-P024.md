# E-P024: Private member access

Code outside a type's implementation domain accessed a private field or method, or attempted an entity method form whose cross-hierarchy semantics are not supported.

## Example

Compile this example with `sioxc --emit ir private_member.siox`.

```siox
module private_member;
struct Data { value: integer }
fn value(data: Data) -> integer {
    return data.value;
}
```

## How to fix

Use an accessible method or exported field when that is the intended API. Internal entity state is not an interface port. Adding `pub` does not by itself implement cross-entity receiver calls.
