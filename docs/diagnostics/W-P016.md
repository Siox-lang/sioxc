# W-P016: Struct literal omits fields

A struct literal supplies only part of the data representation. Omitted fields receive their defaults, which may conceal a forgotten field.

## Example

Compile this example with `sioxc --emit ir incomplete_struct.siox`.

```siox
module incomplete_struct;
struct Data { pub left: integer, pub right: integer }
fn value() -> Data {
    return Data { .left = 1 };
}
```

## How to fix

Initialize the missing fields when they matter, or leave them intentionally at their documented defaults. This warning does not make private fields externally accessible.
