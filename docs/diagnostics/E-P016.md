# E-P016: Access to a private declaration

A qualified path or import crosses a module privacy boundary to a declaration that is not exported.

## Example

Compile this example with `sioxc --emit ir private_import.siox`.

```siox
module private_import;
use auxiliary::visibility::Hidden;
```

The example imports this helper as `auxiliary/visibility.siox`:

```siox
module auxiliary::visibility;
struct Hidden { pub value: integer }
pub struct Visible { pub value: integer }
```

## How to fix

Use the module's public API, or mark the declaration `pub` in its owning module when it should be exported. Import syntax does not override privacy.
