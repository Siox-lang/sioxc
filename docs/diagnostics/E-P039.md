# E-P039: Match expression has no value for some cases

A match expression must produce a value for every possible scrutinee value. Missing cases are an error, unlike the warning for an incomplete match statement.

## Example

Compile this example with `sioxc --emit ir non_exhaustive_value.siox`.

```siox
module non_exhaustive_value;
enum State { Idle, Run }
fn value(n: State) -> integer {
    return match n { State::Idle => 1 };
}
```

## How to fix

Add the missing variants or a meaningful `_` arm. Every arm must produce the declared result type; a default value should represent the intended behavior, not merely silence exhaustiveness checking.
