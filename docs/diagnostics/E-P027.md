# E-P027: Process in an invalid container

Processes describe concurrent behavior of an entity implementation. They are not method bodies for ordinary structs or trait implementations.

## Example

Compile this example with `sioxc --emit ir process_placement.siox`.

```siox
module process_placement;
struct S { n: integer }
impl S {
    process {}
}
```

## How to fix

Use a function inside the struct impl, or put the process in an inherent entity impl. Moving code into a process changes its scheduling domain and should match the intended hardware structure.
