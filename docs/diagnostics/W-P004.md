# W-P004: Unused generic parameter

A declaration's type or value parameter is never used. This lint is about generic parameters, not ordinary function value arguments.

## Example

Compile this example with `sioxc --emit ir unused_parameter.siox`.

```siox
module unused_parameter;
fn value<T>() -> integer { return 1; }
```

## How to fix

Remove the generic parameter or use it in the signature, type shape or implementation. Do not add a meaningless read just to hide an unnecessary parameter.
