# W-P002: Possible combinational latch

A combinational driver does not assign its target on every route, so the target may retain its old value. Explicit clocked state is treated separately.

## Example

Compile this example with `sioxc --emit ir possible_latch.siox`.

```siox
module possible_latch;
entity Cell { enable: Bit in, source: Bit in, data: Bit out }
impl Cell { if enable { data = source; } }
entity E { enable: Bit in, source: Bit in, data: Bit out }
impl E {
    let child: Cell = { .enable = enable, .source = source, .data = data };
}
```

## How to fix

Assign the target on every combinational route, for example with a complete if/else or a default inside the same process. If retained state is intended, model it explicitly with the appropriate clocked behavior.
