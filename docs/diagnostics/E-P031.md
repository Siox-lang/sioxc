# E-P031: Attribute has no value

An attribute read has neither an explicit binding on the object nor a default from its declaration.

## Example

Compile this example with `sioxc --emit ir missing_attr_value.siox`.

```siox
module missing_attr_value;
attr speed: integer for let;
entity E { data: integer out }
impl E {
    let value: integer = 1;
    data = value'speed;
}
```

## How to fix

Add the intended binding or define a suitable default on the attribute declaration. A declared attribute type is not itself a value.
