# E-P014: Conflicting drivers

Independent parallel contexts drive one signal, and its type has no resolution contract to combine their contributions. Assignments in separate processes are separate sources.

## Example

Compile this example with `sioxc --emit ir conflicting_drivers.siox`.

```siox
module conflicting_drivers;
entity Cell { left: Bit in, right: Bit in, data: Bit out }
impl Cell {
    process { data = left; }
    process { data = right; }
}
entity E { left: Bit in, right: Bit in, data: Bit out }
impl E { let child: Cell = { .left = left, .right = right, .data = data }; }
```

## How to fix

Give the signal one driver, often by combining the selection in one process. Use a source-defined `Resolve` type only when multiple-driver resolution is actually intended; it is not a way to hide accidental wiring.
