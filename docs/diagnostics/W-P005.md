# W-P005: Unused import

An explicitly imported declaration is not referenced by this module.

## Example

Compile this example with `sioxc --emit ir unused_import.siox`.

```siox
module unused_import;
use auxiliary::visibility::Visible;
```

The example imports this helper as `auxiliary/visibility.siox`:

```siox
module auxiliary::visibility;
struct Hidden { pub value: integer }
pub struct Visible { pub value: integer }
```

## How to fix

Remove the import, or use the intended imported declaration. Check whether a qualified path or prelude already supplies the name before keeping redundant imports.
