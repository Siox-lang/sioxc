# W-P007: Incomplete match statement

A match statement omits some possible values and has no wildcard. Unlike a match expression, it can execute no arm, so it warns rather than inventing a value.

## Example

Compile this example with `sioxc --emit ir non_exhaustive_statement.siox`.

```siox
module non_exhaustive_statement;
enum State { Idle, Run }
entity E { source: State in, data: integer out }
impl E {
    process {
        data = 0;
        match source { State::Idle => { data = 1; } }
    }
}
```

## How to fix

Handle the missing cases or add an intentional `_` arm. Separately ensure combinational targets are assigned on every route; a default must be in the same driver context.
