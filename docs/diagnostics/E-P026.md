# E-P026: Inherent implementation ownership

An inherent impl must belong to the nominal type's defining module. Kernel types and aliases cannot acquire arbitrary inherent implementations.

## Example

Compile this example with `sioxc --emit ir impl_coherence.siox`.

```siox
module impl_coherence;
impl integer {
    fn value(self) -> integer { return self; }
}
```

## How to fix

Move the impl to the defining module or use an appropriate trait extension under the language's coherence rules. Define a new nominal wrapper when the operation belongs to your own type.
