# E-P019: Statement without an effect

A standalone expression such as `1;` computes a value and discards it. It does not drive a signal or invoke a useful statement operation.

## Example

Compile this example with `sioxc --emit ir no_effect.siox`.

```siox
module no_effect;
fn value() -> integer {
    1;
    return 2;
}
```

## How to fix

Remove the statement, assign its value to the intended writable target, or return it. Use an actual supported control-flow construct instead of a stray name such as `continue`.
