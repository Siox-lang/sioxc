# E-P003: Incompatible types or shapes

A value does not fit the type required by a declaration, assignment, argument or return. Widths, declared array ranges and nominal types are part of that contract.

## Example

Compile this example with `sioxc --emit ir type_mismatch.siox`.

```siox
module type_mismatch;
fn value() -> integer {
    return 1.5;
}
```

## How to fix

Return an integer in this example, or change the declared result if a real is intended. For other mismatches, use a defined explicit conversion or construct the exact required shape; do not assume implicit resizing.

## Trait signatures

A trait implementation must honor the instantiated parameter and result types
declared by its trait. Aliases are transparent and `Self` names the implementing
type; assignment conversions do not silently adapt the method signature.
Keep the required signature and convert inside the body when appropriate, or
change the trait contract deliberately. The secondary label points to the trait
declaration that requires the type.
