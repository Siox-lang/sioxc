# E-P035: Macro expansion failed

A macro cannot expand correctly: its body may name an undeclared parameter, its invocation may match no form, or expansion may exceed the supported recursion bound.

## Example

Compile this example with `sioxc --emit ir macro_expansion.siox`.

```siox
module macro_expansion;
macro invalid($x: expr) { $y }
fn value() -> integer { return invalid!(1); }
```

## How to fix

Correct `$y` to the declared `$x` in this example. For other failures, inspect the invocation and macro definition together; preserve fragment kinds and bound expansion depth.
