# E-P037: Invalid type attribute

A type attribute must describe static shape using permitted type facts and constants. It cannot read arbitrary runtime values or take a reserved attribute name.

## Example

Compile this example with `sioxc --emit ir invalid_type_attr.siox`.

```siox
module invalid_type_attr;
struct Q(Logic[7..0]);
impl Q {
    attr high: integer = 1;
}
```

## How to fix

Choose a nonreserved name and compute it from shape facts such as `self'length`. The example attempts to redefine the system `high` attribute and must use a different name.
