# E-P032: Metadata written as a directive

`#[...]` is reserved for compiler directives such as test discovery and lint control. Ordinary metadata uses attribute declarations and bindings.

## Example

Compile this example with `sioxc --emit ir metadata_directive.siox`.

```siox
module metadata_directive;
#[keep]
entity E {}
```

## How to fix

Use a metadata binding such as `attr keep for signal = true;` on a permitted target. Declare custom metadata with `attr`; do not turn it into a compiler directive.
