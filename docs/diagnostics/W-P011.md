# W-P011: Undriven output or signal

An output endpoint, or an internal signal with no sufficient initialization, has no driver. Storage defaults do not prove that an omitted connection was intentional.

## Example

Compile this example with `sioxc --emit ir undriven_output.siox`.

```siox
module undriven_output;
entity E { data: integer out }
impl E {}
```

## How to fix

Drive or connect the intended endpoint, provide an appropriate initial value where applicable, or remove/change the declaration if it should not be an output. Suppress the lint only when the undriven endpoint is intentional.
