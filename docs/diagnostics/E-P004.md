# E-P004: Writing an input

An input endpoint is driven by its instantiating scope. Its implementation may read it but cannot drive it, including through fields or view leaves.

## Example

Compile this example with `sioxc --emit ir write_input.siox`.

```siox
module write_input;
use std::logic::Bit;
entity E { data: Bit in }
impl E {
    data = '1';
}
```

## How to fix

Move the drive into the parent connection, or write a separate output/local. Change direction only when that matches the hardware interface.
