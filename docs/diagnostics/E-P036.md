# E-P036: Reserved compiler hook misuse

Compiler hook registration and the intrinsic ABI belong to designated core/std declarations. Ordinary source cannot redefine those roles by spelling the same names.

Bare Boolean literals and patterns also require a registered `bool` enum with
source-declared `true` and `false` variants. A matching user type name cannot
replace a missing or invalid hook provider.

## Example

Compile this example with `sioxc --emit ir intrinsic_abi.siox`.

```siox
module intrinsic_abi;
extern "intrinsic" {
    pub fn sqrt(x: real) -> real;
}
```

## How to fix

Call the public library operation, use `extern "C"` for an actual C binding, or define an ordinary source function. Do not claim a reserved lang role to make a user declaration act as a compiler primitive.

Frontend clients resolving Boolean literals must load the core declarations (as
the normal compiler pipeline does). Library authors should check the registered
enum and its variants rather than adding a local type named `Bool` as a fallback.
