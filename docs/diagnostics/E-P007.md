# E-P007: Wrong attribute value type

An attribute binding or default must have the value type its declaration specifies.
Integer metadata must also be a supported compile-time constant expression;
runtime values, division by zero, invalid shifts and overflowing arithmetic
cannot be stored as metadata. Checked arithmetic and integer constants/functions
are supported. Precedence is literal-only because it is read before parsing.

## Example

Compile this example with `sioxc --emit ir invalid_attr_value.siox`.

```siox
module invalid_attr_value;
attr speed: integer for let = "fast";
```

## How to fix

Use an integer default instead of the string in this example. For other attributes, inspect the declared value type and convert explicitly where a conversion exists.
For integer metadata, use a supported constant computation whose intermediate
values fit the kernel integer domain, rather than a runtime signal or an
overflowing operation. Packed-value widths are not limited by this domain.
