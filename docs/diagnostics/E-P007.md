# E-P007: Wrong attribute value type

An attribute binding or default must have the value type its declaration specifies.

## Example

Compile this example with `sioxc --emit ir invalid_attr_value.siox`.

```siox
module invalid_attr_value;
attr speed: integer for let = "fast";
```

## How to fix

Use an integer default instead of the string in this example. For other attributes, inspect the declared value type and convert explicitly where a conversion exists.
