# W-P020: Renamed default constructor

`T::new()` used the synthesized default for a type with no declared `new` method.
That operation is now named `T::default()`; `new` is an ordinary associated name.

## Example

```siox
module renamed_default;
enum State { Idle, Busy }
fn initial() -> State { return State::new(); }
```

## How to fix

Use `State::default()` for the source-defined default, or declare an explicit
`static fn new` if a custom constructor is intended.
