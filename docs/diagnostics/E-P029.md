# E-P029: Attribute object not found

An attribute binding or read cannot identify the declaration it is meant to describe, or an objectless binding has no owning item.

## Example

Compile this example with `sioxc --emit ir unknown_attr_object.siox`.

```siox
module unknown_attr_object;
attr speed: integer for let;
attr speed for missing = 1;
```

## How to fix

Correct the object name/path or place the binding inside its intended owning declaration. Declaring the attribute alone does not create an object to bind it to.
