# E-P018: Invalid assignment target

An assignment needs writable storage. A constant or loop binding cannot be assigned, and a computed expression is not a storage place.

## Example

Compile this example with `sioxc --emit ir invalid_target.siox`.

```siox
module invalid_target;
entity E { data: integer out }
impl E {
    const VALUE: integer = 1;
    fn invalid() { VALUE = 2; }
    data = VALUE;
}
```

## How to fix

Remove the write to the constant in this example. Use a `let` for mutable storage, or copy a loop binding into a local before changing it.
