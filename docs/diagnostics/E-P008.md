# E-P008: No matching method

The receiver's type has no accessible inherent or trait method matching this call.

## Example

Compile this example with `sioxc --emit ir invalid_method.siox`.

```siox
module invalid_method;
fn value(n: integer) -> integer {
    return n.nonexistent();
}
```

## How to fix

Correct the method name, bring the intended trait into scope, or implement the trait for this receiver. Check generic arguments and receiver type rather than relying on another type's same-named method.
