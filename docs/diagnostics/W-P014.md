# W-P014: Earlier assignment is overridden

In one hardware driver context, a later unconditional assignment replaces an earlier one before it can be observed. Separate parallel assignments are independent drivers, not this override rule.

## Example

Compile this example with `sioxc --emit ir dead_assignment.siox`.

```siox
module dead_assignment;
entity E { data: Bit out }
impl E {
    process {
        data = '0';
        data = '1';
    }
}
```

## How to fix

Remove the dead assignment or make the intended selection conditional. This lint does not apply the hardware override rule to sequential testbench stimulus or ordinary function-local updates.
