# W-P010: Combinational feedback loop

The combinational dependency graph contains a cycle without a register. Repeated delta cycles may not settle.

## Example

Compile this example with `sioxc --emit ir combinational_loop.siox`.

```siox
module combinational_loop;
entity Cell { source: Bit in, data: Bit out }
impl Cell {
    let value: Bit;
    value = value or source;
    data = value;
}
entity E { source: Bit in, data: Bit out }
impl E { let child: Cell = { .source = source, .data = data }; }
```

## How to fix

Break the unintended dependency or introduce explicit clocked state at the correct point. Do not add arbitrary delays solely to make an unintended combinational cycle stop oscillating.
