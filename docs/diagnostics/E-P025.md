# E-P025: Private type in a public interface

An exported signature names a private nominal type, so callers cannot name the API it exposes.

## Example

Compile this example with `sioxc --emit ir private_interface.siox`.

```siox
module private_interface;
struct Data { value: integer }
pub fn expose(data: Data) -> integer { return 1; }
```

## How to fix

Export the nominal type as well, or change the public signature to use an accessible type. Keeping a field private is separate from keeping its containing type private.
