# E-P011: Unresolved import

A `use` cannot find the requested module or item in the explicit module graph.

## Example

Compile this example with `sioxc --emit ir unresolved_import.siox`.

```siox
module unresolved_import;
use nonexistent::Item;
```

## How to fix

Correct the module/item path and provide the source dependency through the supported compiler inputs. If the item exists, check whether it is exported; privacy is a separate diagnostic.
