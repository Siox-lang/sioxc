# E-P020: Entity instance in a nonstructural location

Structural elaboration cannot construct an entity instance at this location, such as inside a function or process.

## Example

Compile this example with `sioxc --emit ir instance_placement.siox`.

```siox
module instance_placement;
entity Cell {}
fn value() -> integer {
    let child: Cell = {};
    return 1;
}
```

## How to fix

Move the instance to the entity implementation's structural layer or an appropriate generate construct. Pass data through its ports instead of creating hardware as a function-local value.
