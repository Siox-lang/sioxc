# W-P018: Match ranges share an endpoint

Two match ranges share an endpoint. Siox ranges include both ends and preserve written direction, so the shared value belongs to both ranges and the first arm wins.

## Example

Compile this example with `sioxc --emit ir overlapping_ranges.siox`.

```siox
module overlapping_ranges;
fn value(n: integer) -> integer {
    return match n {
        0..10 => 1,
        10..20 => 2,
        _ => 0
    };
}
```

## How to fix

Make the domains disjoint when overlap is accidental, for example `0..9` followed by `10..20`. Retain overlap only when its priority is intentional.
