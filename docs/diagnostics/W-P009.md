# W-P009: Edge-detected reset

A reset branch uses an edge helper where an asserted-level test is normally required. The branch then runs on a transition rather than throughout the reset level.

## Example

Compile this example with `sioxc --emit ir suspicious_reset.siox`.

```siox
module suspicious_reset;
entity E { reset: Bit in, data: Bit out }
impl E {
    if reset.rising() { data = '0'; }
}
```

## How to fix

Test the reset's asserted value for a level-sensitive reset. Keep edge detection for the clock or when a reset-edge pulse is genuinely the intended behavior.
