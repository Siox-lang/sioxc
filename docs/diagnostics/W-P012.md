# W-P012: Unconnected child input

A child entity input was left unconnected. It holds its default value; the compiler warns because an omitted connection is often accidental.

## Example

Compile this example with `sioxc --emit ir unconnected_input.siox`.

```siox
module unconnected_input;
entity Cell { source: Bit in, data: Bit out }
impl Cell { data = source; }
entity E { data: Bit out }
impl E {
    let child: Cell = { .data = data };
}
```

## How to fix

Connect the parent signal explicitly or retain the default intentionally. An unconnected input is not the retired E-P005 error.
