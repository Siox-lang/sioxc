# E-P010: Analogue syntax is unavailable

This construct belongs to the analogue language phase, not the current digital compiler. It is rejected rather than simulated with invented semantics.

## Example

Compile this example with `sioxc --emit ir analogue_rejected.siox`.

```siox
module analogue_rejected;
fn derivative(x: real) -> real {
    return x'ddt;
}
```

## How to fix

Remove or replace the analogue operation with a digital model. The derivative attribute in this example cannot be enabled by an import or metadata binding.
