# E-P006: Attribute on an invalid target

An attribute declaration lists the kinds of declaration it describes. This binding targets a kind outside that list.

## Example

Compile this example with `sioxc --emit ir invalid_attr_target.siox`.

```siox
module invalid_attr_target;
attr flag: Bool for let = false;
entity E {}
attr flag for E = true;
```

## How to fix

Bind the attribute to an allowed declaration, or correct the attribute declaration's target list if its intended meaning really includes this kind.
