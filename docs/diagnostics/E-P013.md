# E-P013: An entity is not a constant

An entity declaration describes an elaborated hardware instance, not a compile-time data value.

## Example

Compile this example with `sioxc --emit ir const_entity.siox`.

```siox
module const_entity;
entity Cell {}
entity E {}
impl E {
    const child: Cell = {};
}
```

## How to fix

Use `let child: Cell = {};` in a structural location. Use a data type instead if the declaration is meant to hold a constant value.
