# E-P002: Duplicate declaration

Two declarations claim the same name in one namespace. A later declaration does not silently replace the first.

## Example

Compile this example with `sioxc --emit ir duplicate_item.siox`.

```siox
module duplicate_item;
const VALUE: integer = 1;
const VALUE: integer = 2;
```

## How to fix

Rename or remove one declaration. Related locations identify the existing declaration; split impl blocks still share their owner's member namespace.
