# W-P017: Unknown lint name

A source directive or command-line lint option names no lint known to the compiler.

## Example

Compile this example with `sioxc --emit ir unknown_lint.siox`.

```siox
module unknown_lint;
#[allow(not_a_lint)]
fn value() -> integer { return 1; }
```

## How to fix

Correct the lint spelling. Use `warnings` only when you intend to control the whole warning group; an unknown name is not a way to disable an unrelated diagnostic.
