# E-P034: Malformed lint directive

A lint-level directive needs the parenthesized lint list. A bare `#[allow]` does not say which lint to control.

## Example

Compile this example with `sioxc --emit ir malformed_lint.siox`.

```siox
module malformed_lint;
#[allow]
fn value() -> integer { return 1; }
```

## How to fix

Use the intended form, for example `#[allow(unused_param)]`. Check that the lint name exists; unknown names have their own diagnostic.
