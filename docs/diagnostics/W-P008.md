# W-P008: Enum compared to a bare integer

An enum-valued operand is compared with an integer literal. This can compare its numeric discriminant rather than the source value or variant the author intended.

## Example

Compile this example with `sioxc --emit ir suspicious_compare.siox`.

```siox
module suspicious_compare;
fn value(n: Logic) -> Bool {
    return n == 1;
}
```

## How to fix

For Logic/Bit use the intended character literal, such as `'1'`; for Bool use `true`/`false`, and for user enums name the variant. Convert explicitly to an integer only when comparing raw numeric identity is intended.
