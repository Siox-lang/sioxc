# E-P022: Reference to an omitted instance

The selected instance-array index is inside its declared bounds, but concrete generate conditions did not construct that slot.

## Example

Compile this example with `sioxc --emit ir unelaborated_instance.siox`.

```siox
module unelaborated_instance;
entity Cell { data: integer out }
impl Cell { data = 1; }
entity Chain<N: integer> { data: integer out }
impl<N: integer> Chain<N> {
    let stage: Cell[2];
    for i in 0..1 {
        if i < N { stage[i] = Cell {}; }
    }
    data = stage[1].data;
}
entity E { data: integer out }
impl E { let child: Chain<N = 1> = { .data = data }; }
```

## How to fix

Guard the use with the same generate condition, or construct the slot for the selected parameters. This is not an out-of-bounds error; widening the declaration alone does not create the missing child.
