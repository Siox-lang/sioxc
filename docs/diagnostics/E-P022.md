# E-P022: Retired omitted-instance restriction

This code is reserved and is no longer emitted.

Previously, a generate condition could leave an instance-array slot absent even
when that slot was inside the array's declared bounds. A later reference then
reported E-P022.

An instance-array declaration now creates every declared slot. Generate
conditions control its connections, not whether it exists. An unwired slot
simulates using its default inputs; a partially wired array can produce
[W-P021](W-P021.md). References outside the declared index range still produce
[E-P003](E-P003.md).

## Example

Every declared slot exists, even without an explicit connection:

```siox
entity Cell { data: integer out }
impl Cell { data = 1; }
entity Parent { seen: integer out }
impl Parent {
    let cells: Cell[3];
    seen = cells[2].data; // In range: no E-P022.
}
```

## How to fix

If upgrading an old design, an in-range reference no longer needs a matching
generate guard solely to ensure that the instance exists. Keep guards that
express actual design behavior or protect an out-of-range index.
