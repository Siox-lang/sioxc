# E-P021: Nonconstant signal initializer

An implementation signal's initializer is its elaboration-time power-on value. Reading another signal is not a constant initializer.

## Example

Compile this example with `sioxc --emit ir non_constant_initializer.siox`.

```siox
module non_constant_initializer;
entity E { source: integer in, data: integer out }
impl E {
    let stored: integer = source;
    data = stored;
}
```

## How to fix

Use a constant initial value and express the dependency as an assignment or process. A process-local temporary has different lifetime and update semantics; do not change storage kind just to suppress the diagnostic.
