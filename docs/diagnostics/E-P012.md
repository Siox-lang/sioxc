# E-P012: Missing binding type

A `let` declaration needs an explicit type. The initializer does not implicitly determine the declaration's hardware shape.

## Example

Compile this example with `sioxc --emit ir missing_annotation.siox`.

```siox
module missing_annotation;
fn value() -> integer {
    let n = 1;
    return n;
}
```

## How to fix

Write `let n: integer = 1;` in this example. Declare the intended nominal type and bounds for shaped data.
