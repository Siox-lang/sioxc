# E-P001: Unknown name

A value, type or macro name cannot be resolved in the scopes visible at its use. Resolution does not invent missing declarations.

## Example

Compile this example with `sioxc --emit ir unknown_name.siox`.

```siox
module unknown_name;
fn value() -> integer {
    return missing;
}
```

## How to fix

Declare the name, correct its spelling, or import the intended public declaration. Check the owning module and scope before changing visibility.
