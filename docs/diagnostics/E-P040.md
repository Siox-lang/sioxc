# E-P040: Unsupported derived implementation

`#[derive(...)]` generates ordinary comparison implementations for a struct.
Only `Eq` and `Ord` are supported. Generic newtypes do not yet support derive;
generic structs with fields can derive comparisons.

## Example

```siox
module invalid_derive;
#[derive(Display)]
struct Packet { pub value: integer }
```

## How to fix

Use `#[derive(Eq, Ord)]` when you need generated comparisons, or write the
required trait implementation explicitly. For a generic newtype, write the
implementation yourself or use its forwarded base operators where appropriate.
