# W-P006: Unreachable match arm

Earlier match arms already cover every value this arm could match. Match selection uses the first matching arm.

## Example

Compile this example with `sioxc --emit ir unreachable_arm.siox`.

```siox
module unreachable_arm;
fn value(n: integer) -> integer {
    return match n {
        1 => 1,
        1 => 2,
        _ => 0
    };
}
```

## How to fix

Remove the redundant arm or correct/reorder the conditions to represent the intended priority. A wildcard before a specific case makes the later case unreachable.
