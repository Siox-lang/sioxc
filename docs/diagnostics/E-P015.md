# E-P015: Hardware recursion has no finite expansion

A hardware call recurses beyond the inline expansion limit. Hardware recursion needs a finite elaboration-time expansion.

## Example

Compile this example with `sioxc --emit ir recursive_call.siox`.

```siox
module recursive_call;
fn recurse(n: integer) -> integer { return recurse(n); }
entity E { source: integer in, data: integer out }
impl E { data = recurse(source); }
```

## How to fix

Provide a terminating, constant-foldable recursion or express the operation as a bounded loop. This diagnostic is distinct from restrictions on runtime testbench frames (E-P038).
