# W-P021: Unwired instance-array slot

A slot of a partially wired instance array has no construction or port write
connecting it. The slot still exists and its unconnected inputs retain their
defaults. This warning applies when another slot is wired by a construction;
ordinary missing-input diagnostics cover other unwired-instance cases.

## Example

```siox
module unwired_slot;
entity Cell { value: integer in, data: integer out }
impl Cell { data = value; }
entity Top { source: integer in, first: integer out, second: integer out }
impl Top {
    let cells: Cell[2];
    cells[0] = Cell { .value = source };
    first = cells[0].data;
    second = cells[1].data;
}
```

## How to fix

Connect each intended slot explicitly. Leave a slot unwired only when its
default-input behavior is intended; an unwired slot is not a missing instance.
