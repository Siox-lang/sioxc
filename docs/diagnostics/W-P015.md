# W-P015: Metadata has no implemented effect

The attribute is declared and may be preserved as metadata, but no current compiler stage implements the behavior its use suggests.

## Example

Compile this example with `sioxc --emit ir unimplemented_attr.siox`.

```siox
module unimplemented_attr;
entity E { data: Bit out }
impl E {
    let value: Bit = '1';
    attr keep for value = true;
    data = value;
}
```

## How to fix

Do not rely on this binding to change simulation or optimization. Remove it when unnecessary, or retain it deliberately as tool-facing metadata and control the lint explicitly.
