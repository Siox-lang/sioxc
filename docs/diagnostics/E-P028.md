# E-P028: Retired single-process scheduler restriction

This code is reserved and is no longer emitted. An early migration scheduler
accepted only one foreground process per testbench; the fixed Process runtime
schedules multiple processes through the common pipeline.

## Example

The following shape used to encounter the migration restriction. It is now
valid; compile it with `sioxc --test example.siox`.

```siox
module example;
#[test] entity T {}
impl T {
    process { await 1ns; }
    process { await 2ns; }
}
```

## How to fix

There is no current source restriction to work around. If this code appears,
check which compiler binary your tool is running and update an old compiler.
Do not merge independent processes solely to satisfy this retired diagnostic.
