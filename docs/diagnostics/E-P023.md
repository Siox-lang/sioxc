# E-P023: Compile-time file input failed

A compile-time `read<T>` could not read its input, or the contents do not fit the declared result format.

## Example

Compile this example with `sioxc --emit ir compile_time_io.siox`.

```siox
module compile_time_io;
use std::bits::unsigned;
entity E {}
impl E {
    let data: unsigned[8][2] = read<unsigned[8]>("__siox_ui_missing_file__.bin");
}
```

## How to fix

Provide the intended file and correct path, then check element format and length. If the read is meant to happen during simulation, put it in the appropriate runtime context rather than a signal initializer.
