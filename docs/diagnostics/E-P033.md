# E-P033: Attempt to lower a forbidden lint

An inner directive would lower a lint level already set to `forbid`. `forbid` deliberately cannot be overridden.

## Example

Compile this example with `sioxc --emit ir forbidden_lint.siox`.

```siox
module forbidden_lint;
#[forbid(unused_param)]
#[allow(unused_param)]
fn value<T>() -> integer { return 1; }
```

## How to fix

Remove the inner lowering directive, fix the lint, or change the outer policy where you control it. A command-line `-F` is also binding and cannot be weakened by source directives.
